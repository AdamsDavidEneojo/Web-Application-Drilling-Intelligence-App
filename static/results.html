Overview

How to read Axelrod predictions.

The dashboard returns three ROP estimates and lets you compare them with actual field values. Use the results as decision support, then validate them against drilling context, sensor quality, and operational constraints.

Open Predictor Back to App Overview

ROP Average

The model's estimated average rate of penetration for the provided drilling parameters. This is the main baseline result to compare against field performance.

ROP Cut Unit

A cut-focused ROP estimate that helps review drilling efficiency against the depth-of-cut and related operating inputs.

ROP Fast

A faster-case ROP estimate that can help identify upside performance, but should still be checked against safety and equipment limits.

Predicted vs Actual

  • Predicted values come from the model after the eight input signals are processed.
  • Actual values are the real field measurements you enter after a run or interval.
  • Close values suggest the model matched the operating condition well.
  • Large gaps can mean unusual drilling conditions, noisy sensor data, missing context, or that the model needs more representative training data.

Best Practice

Keep input units consistent, enter complete actual values before comparing, and review the chart as a trend aid rather than a single final answer. If the model status is still loading, wait for it to show ready before running a prediction.
